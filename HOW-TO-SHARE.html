How to Share Your Prototype

Simple guide to make SmartCart AI accessible from any device

❓ Why doesn't localhost:8081 work for others?

Simple answer: localhost means "this computer only." When your friend types that link on their phone, their phone searches for a server on their own phone — not yours. It will always fail.

🚫 localhost and 127.0.0.1 are never accessible from other devices, no matter what.

Think of localhost like your home address written as "My house" — only you know where that is.

📶 Option A — Same WiFi (Works Right Now)

✅ Already configured

Your server is already listening on all network interfaces. Anyone on the same WiFi network as you can open this link:

http://192.168.0.167:8081/index.html

⚠️ This IP address may change. Run ipconfig in PowerShell and look for "IPv4 Address" to get the current one.

Steps for your friend:
1
Connect their phone/laptop to the same WiFi as your computer
2
Make sure your SmartCart server is running (double-click START-SERVER.bat in the smartcart folder)
3
Open their browser and type exactly: http://192.168.0.167:8081/index.html
4
SmartCart AI loads on their device ✅
⚠️ Limitation: This only works when both devices are on the exact same WiFi. Friends on different networks (mobile data, different WiFi) cannot access this.
⚠️ Firewall note: If friends on same WiFi still can't connect, Windows Firewall may be blocking port 8081. You need to allow it manually — see Step 4 in the Firewall Fix section below.

🛡️ Firewall Fix (if same-WiFi friends still can't connect)

1
Press Windows key, type Windows Defender Firewall, click it
2
Click "Advanced settings" on the left
3
Click "Inbound Rules" → then "New Rule..." on the right
4
Choose Port → Next → TCP → type 8081 → Next → Allow the connection → Next → check all three (Domain, Private, Public) → Next → Name it SmartCart → Finish

🌍 Option B — Public Link via ngrok (Anyone, Anywhere)

Works from any network · Free
1
Go to https://ngrok.com → click Sign up free → create an account
2
After signup, go to dashboard.ngrok.com/get-started/setup → download the Windows installer
3
Run the installer, then open PowerShell and paste the authtoken command from the ngrok dashboard (looks like: ngrok config add-authtoken YOUR_TOKEN)
4
Make sure your server is running (double-click START-SERVER.bat)
5
In a new PowerShell window, run: ngrok http 8081
6
ngrok shows a public URL like https://abc123.ngrok-free.app — share that with anyone!
⚠️ Limitation: The URL changes every time you restart ngrok (on free plan). You must keep both the server and ngrok running. Stop either one and the link dies.

🌐 Option C — GitHub Pages (Permanent Public Link — Best Option)

✅ Best for sharing · Free forever · No server needed

Since your entire SmartCart AI is a single file (index.html), you can host it for free on GitHub Pages. Your friends get a permanent link like:

https://YOUR-USERNAME.github.io/smartcart/

Step-by-step (takes about 5 minutes):

1
Go to github.com → Sign up for a free account (or log in)
2
Click the + button (top right) → New repository
3
Name it smartcart → make sure it's set to Public → click Create repository
4
On the next screen click "uploading an existing file" → drag your index.html from the smartcart folder into the browser window
5
Click Commit changes (green button)
6
Go to repository Settings → scroll to Pages → under Source choose Deploy from a branch → Branch: main → folder: / (root) → click Save
7
Wait 1–2 minutes → refresh the Pages settings page → GitHub gives you your public URL!
✅ This is the best option. The link works from any phone, any laptop, any country, 24/7, even when your computer is off. Completely free. No installs.
